# Demo video


The demo video presents Pick & Sip, demonstrates its main features on the deployed web application. It covers the application flow, including managing cafés and visits, using Choose for Me, and viewing the responsive mobile layout.

**Link:** [Pick and Sip Demo Video](https://drive.google.com/file/d/1E5_DvUjKVKH18osxzcdraVV8EU23N20G/view?usp=sharing)

## Demo Video Structure

### 1. Introduction and the Problem

Introduces Pick & Sip, its intended user, and the problem it aims to solve.

### 2. Application Demo

Demonstrates the deployed application end to end, including all pages, adding a café and a visit, using Choose for Me, and viewing the mobile layout.

### 3. Technology Used and Brief Code Walkthrough

Explains the technologymstack and walks through a relevant part of the code.

### 4. What's Next

Discusses the application's limitations, possible improvements, and future enhancements.

## Before Recording

- [x] Open the deployed Pick & Sip website beforehand and make sure the frontend and backend are responding correctly.
- [x] Record the **deployed application**, not `localhost`.
- [x] Check that the dashboard, café list, café details, Add Café, Add Visit, Choose for Me, and Profile pages load correctly.
- [x] Prepare realistic café data so the demo does not start with an empty database.
- [x] Test the Choose for Me feature and make sure the prepared café data produces a suitable result.
- [x] Check the mobile layout on a phone or mobile viewport.
- [x] Prepare the relevant code file for the technology walkthrough.
- [x] Close unrelated browser tabs and check that no personal messages, sensitive information, or `.env` files are visible during recording.
- [x] Do a full practice run to check the flow, timing, narration, and  transitions between the application and code editor.
- [x] Make sure the microphone is clear and the screen recording captures readable text and the relevant application interactions.
- [x] Keep the demo within the required three-to-five-minute duration.
